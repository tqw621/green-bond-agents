## 定价校准的范围

2026 年 11 月补充了 jieba 决策理由分词和来源筛选，matplotlib／seaborn 静态图表，以及页面和命令行报告导出。词频可追溯至原始理由，历史来源缺失记录单独标记。验证覆盖重复理由计数、来源和环节过滤、旧数据读取、ZIP 导出和 Streamlit 页面操作。使用说明与字段约定见 [接口文档](../docs/接口文档.md)。正式样本及真实模型联调仍需归档。

运行 `python -m research.evaluate_pricing` 可复算，数据在 `research/public_mtn_cases.csv`。样本期限 3–5 年、AAA、固定利率、面值发行。基准取发行前最近可用日的国债曲线，3 年点使用 2 年和 5 年线性插值。[国债数据](https://data.eastmoney.com/cjsj/zmgzsyl.html)

四笔后期样本的 MAE 分别为 188.75、10.25、9.90 bp，对应原规则、历史票息中位数、国债收益率加历史中位利差。去掉校准组中与验证组同一发行人的记录后，后两种误差为 6.75 和 9.48 bp。样本规模限制了方法排名。代码接受有来源的市场基准及利差，项目级参数应待更大样本验证。有效申购金额仅描述公开簿记结果，可能包含承销商自营及关联方认购。

## 可检验的行业创新方向

| 痛点 | 可检验的问题与所需数据 |
| --- | --- |
| 绿色项目资格与披露质量 | 对同一目录版本，比较用途、项目证据、测算方法与补件记录。可以测试证据缺失和项目本身不合格对放行的影响。[目录通知](https://app.www.gov.cn/govdata/gov/202507/15/532790/article.html) |
| 绿色溢价随市场和样本口径变化 | 对同发行人、同期限、近发行日的普通债进行配对。检验票息利差和显性发行成本，避免把信用利差当作绿色溢价。[中央结算公司白皮书](https://www.cnfin.com/zs-lb/detail/20260623/4430535_1.html) |
| 认购总量与独立市场需求不同 | 分开记录合规申购、有效申购、包销、自营及关联方获配，研究剔除部分内部需求后，认购覆盖率如何变化。[三峡发行公告](https://www.chinamoney.com.cn/chinese/zqfxgg/20251226/3259003.html) |
| 取消、推迟与最终失败容易混淆 | 以同一发行项目匹配每次尝试，检验取消后重新发行的时间、规模和利率变化。[中电建取消](https://www.chinamoney.com.cn/chinese/qtir/20260729/3386254.html) · [重新发行](https://www.chinamoney.com.cn/chinese/ltss1/20260731/3388413.html) |
| 高等级发行人集中，结论外推受限 | 同时报告所有制、规模、评级和可得样本量。有低评级样本后检验模型能否迁移。[中国货币网共同分类目录样本](https://www.chinamoney.com.cn/chinese/rdgz/20261015/3430095.html) |
| 存续期环境效益难纵向比较 | 把募集说明书中的预期目标与实际资金投向、项目进度和减排数据按项目链接，比较预测偏差及更新频率。[交易商协会机制通知](https://www.nafmii.org.cn/ggtz/tz/202410/t20241010_319907.html) |
| 二级市场流动性和一级发行表现常被混用 | 将发行覆盖、成交和换手分别建模。用市场数据检验定价时的流动性假设。[中债资信年报](https://www.chinaratings.com.cn/upload/docs/2026-05-13/doc_6651778651857.pdf) |
